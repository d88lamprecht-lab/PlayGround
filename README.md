## NIGHTFALL // SECTOR 07

A neon-soaked wave-survival first-person shooter built with Three.js. No build
step, no external assets: the city, arena, weapons, enemies, textures, audio and
effects are all generated procedurally at runtime.

**Run it:** open `index.html` through any static server (for example
`python3 -m http.server`) and press **DEPLOY**.

### Controls

| Action | Desktop | Mobile |
| --- | --- | --- |
| Move | `W` `A` `S` `D` | Left joystick |
| Look | Mouse (click to lock) | Drag right side of screen |
| Fire | Left mouse button | Fire button |
| Aim | Right mouse button | AIM button |
| Reload | `R` | RELOAD button |
| Jump | `Space` | JUMP button |
| Sprint | `Shift` | Push joystick fully |
| Pause | `Esc` or the pause button | Pause button |

Survive escalating waves of WASP drones, WARDEN troopers and TITAN heavies.
Headshots deal bonus damage, kills build a score combo, and the rooftop data
core must stay intact.
